# Batch40 UI Notes

The Challenge Session primary surface should feel like a desktop analysis instrument, not a dashboard made of independent colored cards.

Design rules applied in Batch40:

1. Prefer shared pane boundaries and continuous surfaces over isolated rectangles.
2. Use status dots, rails, typography and separators before filled backgrounds.
3. Keep the result as a command/result line, not a large hero card.
4. Keep file inventory as a tree/list, not one card per file.
5. Keep solver execution as one vertical timeline.
6. Keep missing input, local AI handoff and manual verification in one context inspector.
7. Move verbose findings and file detail into a bottom evidence dock.
8. Reserve accent color for state and action, not full panel fills.
